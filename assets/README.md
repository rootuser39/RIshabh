# Observatory artwork

Original vector artwork for this repository's README, generated by
`scripts/build_observatory.py` using only the Python 3 standard library.

```sh
python3 scripts/build_observatory.py
```

The SVGs are self-contained: no JavaScript, remote fonts, third-party image
services, trackers, credentials, scheduled jobs, or runtime dependencies.
The orbital sculpture and signal trace are decorative, not a physical
simulation, live telemetry, benchmarks, or project completion indicators.

CSS animations respect `prefers-reduced-motion`. When animation is unavailable,
each asset remains a complete still image. The README supplies a portrait hero
for small screens, and its fixed-width project images wrap to fit the page.

`field-notes-039.png` is the previous banner and remains preserved in the repo.
