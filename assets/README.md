# Void Observatory artwork

Original vector artwork for this repository's README, generated by
`scripts/build_observatory.py` using only the Python 3 standard library.

```sh
python3 scripts/build_observatory.py
```

The SVGs are self-contained: no JavaScript, remote fonts, third-party image
services, trackers, credentials, scheduled jobs, or runtime dependencies.
The orbital sculpture and signal trace are decorative, not a physical
simulation, live telemetry, benchmarks, or project completion indicators.

CSS animations respect `prefers-reduced-motion` when an SVG is opened directly.
The README additionally uses `<picture>` sources to select animation-free SVGs
from `assets/still/` for reduced-motion settings. This works even in browsers that
do not propagate media preferences into an SVG loaded as an image. The generator
rebuilds both versions. Each still image shows the complete open-wing drawing.
The README supplies a portrait hero for small screens, and its fixed-width project
images wrap to fit the page.

The **Void Dragon** is original pixel art authored in `scripts/void_dragon.py`.
Its 64 × 56 pixel drawing has three discrete wing poses, a hovering body,
a gently swaying tail, blinking cyan eyes, and occasional particle breath.
The artwork places it at the edge of the hero and footer. A separate
`void-dragon.svg` portrait makes the companion easy to view and reuse.

`observatory-mobile.svg` and `void-footer-mobile.svg` provide separate mobile
compositions. All dragon animation stops with a reduced-motion preference;
the open-wing pose stays visible. GitHub README images cannot support page-wide
floating overlays, pointer-following behavior, or pet interactions. The companion
is animated inside the self-contained SVG images.

`field-notes-039.png` is the previous banner and remains preserved in the repo.
